# DATV ATEM receiver controller

ESP32 controller project for routing six DVB-S2 receiver lock/alarm signals to an original Blackmagic ATEM Television Studio, with a locally served control page.

The initial firmware and commissioning documentation are being developed on the [`codex/esp32-lock-controller` branch](https://github.com/mathisono/DATV_io_AtemStudio_controler/tree/codex/esp32-lock-controller). See the repository's [pull requests](https://github.com/mathisono/DATV_io_AtemStudio_controler/pulls) for the complete implementation and its validation record.

The receiver alarm's electrical specification and physical ESP32/ATEM commissioning are required before field deployment.
